# 数据库账号推荐接口后端实现 Prompt

请在当前后端项目中实现“用户账号推荐”接口。先阅读现有项目结构、鉴权中间件、用户模型、关注关系模型、屏蔽关系模型、统一响应结构和测试约定，然后沿用现有架构完成实现，不要另起一套框架。

## 目标

为 iOS 客户端提供当前数据库中的可推荐账户。客户端已经接入以下接口：

```http
GET /users/recommended?limit=18&exclude_user_id=<正在查看的主页用户ID>
Authorization: Bearer <token>
```

接口必须要求登录，并使用当前登录用户作为推荐请求人。

## 查询参数

- `limit`：可选，默认 `18`，限制在 `1...50`。
- `exclude_user_id`：可选；传入时排除该用户，避免在某个用户主页的推荐模块中再次推荐主页本人。

## 推荐规则

从当前数据库已有用户中返回账户，至少满足：

1. 排除当前登录用户。
2. 排除 `exclude_user_id`。
3. 排除已删除、已停用、封禁、注销或不可展示的账户。
4. 排除系统账户、内部测试账户和机器人账户（按项目已有字段判断；如果没有此类字段，不要臆造迁移）。
5. 排除当前用户已屏蔽的账户，以及屏蔽了当前用户的账户。
6. 不返回邮箱、手机号、密码散列、登录信息、设备信息等敏感字段。
7. 可以推荐已关注或未关注账户，但必须正确返回双方关系字段。
8. 优先保证每次能返回足够数量的真实账户。小规模数据库可以随机排序；如果数据量较大，不要直接对全表使用昂贵的 `ORDER BY RANDOM()`，应使用项目数据库适合的可扩展抽样或稳定散列排序方案。

如果项目已有推荐、活跃度或共同关注信号，可以优先使用；如果没有，采用安全的随机/轮换推荐即可，不需要新增复杂推荐算法。

## 响应格式

必须沿用项目现有统一 API 包装结构，返回：

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "users": [
      {
        "user_id": "123",
        "username": "alice",
        "nickname": "Alice",
        "avatar_url": "https://example.com/avatar.jpg",
        "bio": "hello",
        "following_count": 12,
        "follower_count": 34,
        "followed_by_me": false,
        "follows_me": false,
        "is_friend": false
      }
    ],
    "has_more": false,
    "next_page": null
  }
}
```

字段要求：

- `user_id` 必须是可稳定转换为字符串的用户 ID。
- `username`、`nickname`、`avatar_url`、`bio` 缺失时返回空字符串，不要返回不兼容类型。
- `following_count`、`follower_count` 缺失时返回 `0`。
- `followed_by_me`：当前登录用户是否关注该推荐用户。
- `follows_me`：该推荐用户是否关注当前登录用户。
- `is_friend`：按照项目现有好友定义计算，不要自行改变业务规则。
- 当前客户端只取首批结果，因此本期可以返回 `has_more: false` 和 `next_page: null`；如果后端已有分页基础设施，也可以实现一致的分页。

## 性能与安全

- 避免 N+1 查询；账户基础信息、关注状态和计数应批量查询或通过合理联表/预加载完成。
- 对查询参数做类型和边界校验。
- 复用现有鉴权、错误处理、日志和响应序列化方式。
- 不泄露被屏蔽用户或不可展示账户的存在。
- 为高频访问设置合理索引；不要为了本接口破坏已有表结构或关注逻辑。

## 测试

新增项目现有测试框架下的自动化测试，至少覆盖：

1. 未登录请求被拒绝。
2. `limit` 默认值、最小值和最大值约束。
3. 排除当前用户和 `exclude_user_id`。
4. 排除停用、删除、系统和双向屏蔽账户。
5. 返回字段及统一响应结构完全符合约定。
6. `followed_by_me`、`follows_me`、`is_friend` 状态正确。
7. 数据库可推荐账户不足时返回实际数量且不报错。
8. 没有可推荐账户时返回空 `users` 数组。
